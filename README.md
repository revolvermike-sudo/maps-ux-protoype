# UX-прототип ленты рекомендаций

Статический прототип без сборки: его можно открыть локально через любой веб-сервер и разместить в Vercel или Netlify без отдельной настройки сборки.

## Первый тест

- Стартовый экран карты из Figma.
- Переход в ленту по нажатию на нижнюю штору или свайпу вверх.
- Горизонтальные категории, смена содержимого ленты.
- Сетка из двух карточек и открытие карточки места.

## Поведение ленты

- Фотографии в плитке листаются горизонтальным свайпом или перетаскиванием мышью. Тап открывает карточку места. Для клавиатуры доступны стрелки влево/вправо на плитке.
- Штора следует за перетаскиваемым dragger’ом; отпускание после движения более 60 px открывает или закрывает её. Переход занимает 420 ms, с замедлением к концу. Учитывается настройка уменьшения движения.
- Начиная с «Поесть», выбранный интент плавно прокручивается к центру. Порядок не меняется. Первые два интента возвращают карусель к началу.
- Размеры при ширине 375 px: плитка 167,5 × 303,33 px, фотография 167,5 × 223,33 px.
- Количество мест: «Для вас» — 12; «Продлить лето» — 6; «Поесть» — 6; «Погулять» — 4; «С детьми» — 4; «Развлечься» — 2; «Выпить» — 4. Поиск и сохранённое показывают реальные совпадения, без дублирования для чётности.
- Данные организаций, фотографии, логотипы и доступные блюда меню сохранены из публичных карточек Яндекс Карт. Это фиксированный набор для исследования, не онлайн-данные. Бронирование — демонстрационное, запросы не отправляются.

Проверено в браузере: drag вверх/вниз и отмена короткого жеста; клик по dragger’у; свайп фото в обе стороны; открытие карточки и возврат; все категории; центрирование «Поесть» и «Выпить»; вертикальная прокрутка с неподвижной шапкой; экран 375 × 812 без горизонтального переполнения.

## Второй тест

- Кнопки «Тест 1» и «Тест 2» на десктопе переключают варианты. Каждый выбор начинает сценарий с главной карты.
- Прямые ссылки: `/?test=1` и `/?test=2`. При перезагрузке выбранный тест сохраняется в URL. На телефоне можно открыть соответствующую ссылку без служебного переключателя поверх макета.
- Использован Google Tile из Figma: L — 290 × 422 px, M — 245 × 427 px, фото — 244 px по высоте. Шапка с заголовком «Местный вайб» и погодой — 68 px, остаётся на месте при вертикальной прокрутке.
- Три горизонтальных ряда: «Поесть» (6), «Погулять» (4), «Развлечься» (2). Последний срез использует общий тег `fun`: Новая Голландия и Севкабель Порт, как в Тесте 1.
- Всего 12 плиток и 10 уникальных организаций из Теста 1: два места повторяются в «Погулять» и «Развлечься». Кофейни остались только в Тесте 1. Карта, фотографии и компонент карточки места общие. Возврат из места сохраняет позицию прокрутки ленты и ряда.
- Ряды листаются свайпом, трекпадом, перетаскиванием мышью и стрелками клавиатуры. В отличие от Теста 1, горизонтальный жест здесь листает места, а не фотографии внутри плитки.
- «Всё популярное» и «Показать ещё» открывают дискавери-режим соответствующего среза.
- Погода и статусы работы — фиксированный снимок для UX-теста, а не онлайн-виджеты.

Проверка набора данных и компонентов: `node work/check-google-feed.mjs`.

## Дискавери-режим

- В Тесте 1 вход через «На карте»: сохраняются категория, набор и порядок отфильтрованных организаций. В Тесте 2 вход через кнопку среза: используются все организации этого среза.
- В обоих тестах общий экран по Figma `6105:11576`: статичная карта, снизу штора высотой 120 px, заголовок категории, поиск и крестик. Внутри шторы — общие маленькие плитки, как в обоих макетах перехода.
- Тап по заголовку/ручке или drag раскрывает и сворачивает штору. Плитки поддерживают свайп фотографий, сохранение и открытие общей карточки места. Возврат из карточки сохраняет положение шторы; крестик возвращает на главный экран. Escape сначала сворачивает штору, затем выходит из режима.
- Карты экспортированы без перерисовки из узлов Figma: `all:6107:15410`, `food:6107:15714`, `walk:6107:16016`, `kids:6107:16318`, `fun:6107:16620`, `drink:6107:16936`. Метки и подписи на них — часть статичного изображения, не кликабельные организации базы прототипа.
- Для «Продлить лето» используется карта «Для вас»: отдельного состояния в предоставленной секции нет. Заголовок и набор организаций соответствуют выбранной категории.
